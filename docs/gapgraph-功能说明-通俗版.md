## 一、先说这是什么东西

**一句话：给学习做"体检 + 处方"。**

去医院体检，你拿到的不是一段医嘱散文，而是一张表：哪几项超标、超了多少、需不需要复查。然后医生按严重程度给你排一个复查顺序。

这个软件做的就是这件事，只不过体检的对象是"你对某个知识板块的掌握情况"：

- **体检报告** = 一张会变色的知识地图（红的地方是你塌了的考点）
- **体检指标** = 每个考点旁边的一个分数（0 到 1，越接近 1 越稳）
- **处方** = 明天打开软件，只给你三张便利贴，每张写着"今天做这个，大约 12 分钟"

它不是"AI 帮你生成一张漂亮的思维导图"，而是**一张会随做题变色的地图 + 一个每天帮你排课的助理**。

## 二、现在做到哪儿了

### 2.1 三分钟总览

| 维度 | 状态 |
|---|---|
| 能完整走通的流程 | 大厅 → 建板块 → 摸底 → 今日任务 → 做题 → 看缺口 → 换章节 |
| 内置内容 | 高考数学·函数板块：42 个考点、147 道题、41 段讲解、82 张卡片 |
| 能装的板块 | 内置 1 个 + **任何章节都能现场生成**（实测做过：多元函数微分学、烷烃、化学反应速率、虚拟语气） |
| 演示保底 | 双击即开，不要 Node、不要服务器、不要网络 |
| 代码规模 | 约 4600 行（不含文档），90 条自动测试 |

### 2.2 已经能用的（用户视角）

| 你想要的 | 现在能不能 | 说明 |
|---|---|---|
| 打开就看到"我在学什么、学到哪" | ✅ | 大厅：所有板块 + 进度 + 上次学习时间 |
| 学一个考纲里没有的章节 | ✅ | 写个章节名，20 秒生成一张 20 个考点的图 |
| 不知道哪儿不会，先测一下 | ✅ | 12–15 道题的自适应摸底，答错会顺藤摸瓜往前置钻 |
| 每天不知道学什么 | ✅ | 每天三张卡，按时长上限装，装不下就不给 |
| 做完题看到进步 | ✅ | 分数和颜色当场变，还会告诉你"从黄变成红" |
| 错的地方知道自己错在哪一类 | ✅ | 六种错因，不同错因扣分不同 |
| 想看清"是简单题不会还是难题崩" | ✅ | 热力表按易/中/难分列 |
| 遇到不懂的当场问 | 🟡 | 能问，但需要开着一个小服务（见 3.3） |
| 把问到的存下来复习 | 🟡 | 能收藏，但还没接进每日复习 |
| 断网也能用 | ✅ | 除了"问 AI"，其他全在本地 |

### 2.3 还没做的（以及为什么先不做）

| 功能 | 状态 | 为什么 |
|---|---|---|
| 卡片自动排进每日复习 | 计划中（最优先） | 现在收藏了不会自动复习，这个动作没有回报 |
| 拍照/粘贴批量导入题目 | 不做 | 切题准确率不稳，现场演示风险高；改用"按需生成"替代 |
| 主观题自动判分 | 不做 | 判错一次就毁掉信任，改成按采分点自己打勾 |
| 手机版 | 不做 | 第一版只做电脑版 |
| 云同步 / 多人协作 | 不做 | 数据全存本地，是隐私设计的一部分 |
| 账号体系 | 不做 | 中考用户是未成年人，能不注册就不注册 |

## 三、设计层面的底层逻辑

这一节是全篇最重要的部分：**产品的每一个具体做法，都是从下面九条原则推出来的**。看懂这九条，你能自己判断任何一个新需求该不该做。

### 原则 1：一个颜色只编码一件事

图上有红、橙、黄、绿、灰五种颜色。它们**只表示掌握度**，不表示重要性、不表示考频、不表示难度。

**为什么**：如果颜色同时表示两件事，用户永远分不清"这格是红的是因为它难，还是因为我不会"。

**这条原则逼出来的决定**：
- 考频权重不用颜色表示，改用**圆的大小**
- 易混关系不用红色表示（红色已经被掌握度占了），改用**紫色虚线**
- 灰色 ≠ 会。灰色是"我们不知道"
- 根节点永不上色（它不是考点，没有掌握度）

### 原则 2：自评是"先验"，不是"证据"

用户勾"我会"的时候，软件只当作"可能有六成会"，不当满分。

**为什么**：人对自己的判断系统性偏高——刚听完课的人几乎都觉得懂了。用不可信的尺子去量东西，整个系统的输出都不可信。

**这条原则逼出来的决定**：
- 自评"会"只给 0.3 分（橙色），要靠做题往上推
- 自评"学过不会"给 0.5 分（红色），但答对几次能推到绿色
- 一旦答错，立刻掉分，并提示"你之前标的是已掌握"

### 原则 3：留存是"折扣"，不是"加分"

记忆会衰退，衰退是**打折**，不是额外奖励。

**为什么**：早期的算法写成了"六成看能力 + 四成看记忆"。结果是——五道题全错，但因为"刚做完、还记得"，分数居然还有 0.376（橙色）；更荒唐的是，第一道错题会让分数从 0.50 **涨**到 0.539。

**这条原则逼出来的决定**：
- 改成"能力 × (0.6 + 0.4 × 记忆)"，全错就是 0.059（红色）
- **没有任何一条路径能让错误提高分数**
- 这条是踩了坑才立起来的，当时测试直接抓到了"错题涨分"

### 原则 4：少即是够

每天只给三张卡，装不下就不给，宁可今天没事干也不堆任务。

**为什么**：备考的人不缺任务，缺的是"今天只做这三件就够"的确定感。一天给九件事，第三天就卸载了。

**这条原则逼出来的决定**：
- 硬上限三张卡
- 时长上限到了就停，不"顺手再加一张"
- 一张补救卡固定三道题——刚好够把一格从橙推到黄
- 提示文案写的是"装不下就不排"，而不是"还有更多任务待完成"

### 原则 5：默认干净，点谁看谁

地图上默认**不画任何关系箭头**，只有点中某个考点，才显示和它相关的几条。

**为什么**：40 个考点把前置关系全画出来，是一团乱麻。我们真的做过一个"地基模式"专门全画出来，结果自己也看不懂，已经删掉。

**这条原则逼出来的决定**：
- 前置箭头默认隐藏
- 点空白处取消选中，箭头跟着收起
- 圆环上的标签会自动找"最空的位置"，撞上节点就换地方
- 讲解、卡片、AI 提问都放在右栏，不往图上堆

### 原则 6：每个判断都必须能追溯到记录

软件说"你这个考点塌了"，你必须能查到是哪几次答题导致的。

**为什么**：不能追溯的判断，用户没法反驳，也就没法信任。

**这条原则逼出来的决定**：
- 每道题的作答都留着：时间、对错、难度、你选的自评、你选的错因
- 热力表格子里写的是"2/3"（三次里对两次），不是百分比
- 可信度单独显示：做了几道题，决定这个分数能信几分
- 没数据就说"还没数据"，不显示预估分

### 原则 7：AI 是加速器，不是发动机

断网、没有钥匙、服务没开——除了"问 AI"，其他功能必须照常。

**为什么**：学校机房、自习室、比赛现场都可能断网。

**这条原则逼出来的决定**：
- 41 段讲解、82 张卡片、147 道题都是**提前生成好、随软件分发**的，打开秒出、不联网
- 拼图、算分、排任务、热力表全在本地
- 没有 AI 服务时，界面上明确写"实时 AI 未连接"，而不是转圈或报错

### 原则 8：不预生成，用到才做

新建章节时**不会**一次生成整本题库，只备够摸底用的几道；用户点某个考点，才为那个考点现做三道。

**为什么**：用户看到图不等于要立刻做一百道题。预生成让"建一个章节"从 20 秒变成 5 分钟，而且大部分题永远不会被碰。

**这条原则逼出来的决定**：
- 建章节只备 7–9 道摸底题（约 20 秒）
- 考点面板上写着"现出 3 道题"，点了才做（约 6 秒）
- 今日任务的卡如果碰上没题的考点，点"开始"时才出题
- 出过的题存在本地，下次还在，不重复花钱

### 原则 9：宁可粗糙，不要假精确

不给"掌握度 73.4%"，给五档颜色 + 可信度；不给"你能考 108 分"，给"105 到 118"；一条数据都没有时，显示"还没数据"。

**为什么**：精确的数字像承诺。一旦承诺兑现不了，用户不再信任何数字，包括正确的那些。

**这条原则逼出来的决定**：
- 做过题少于 3 道的格子，提示"数据不足"
- 热力表里没做过的难度显示"—"，不等于 0 分
- 预估分在没有任何数据时显示"还没数据"

### 九条原则怎么变成产品

| 原则 | 直接对应的做法 | 如果违反会怎样 |
|---|---|---|
| 一个颜色一件事 | 紫色=易混、大小=考频、灰色=不知道 | 用户分不清"红是因为难还是因为不会" |
| 自评是先验 | 自评"会"只给橙色 | 全绿地一考就崩，用户不再信这个软件 |
| 留存是折扣 | 全错一定红，错题绝不涨分 | 数据显示"还行"，掩盖真实缺口 |
| 少即是够 | 三张卡、装不下不排 | 第三天就卸载 |
| 默认干净 | 箭头点谁看谁 | 图糊成一片，谁都看不懂 |
| 判断可追溯 | 每题留档、格子里写 2/3 | 用户无法反驳也无法信任 |
| AI 不是发动机 | 讲解卡片题目全预生成 | 断网即废 |
| 用不到不生成 | 按需出题 | 建章节等 5 分钟，建完没人做 |
| 不假精确 | 区间、"还没数据" | 数字被当真，兑现不了就崩盘 |

## 四、原计划里被改掉的地方（当时的判断 vs 现在的实际）

这一节保留下来，是为了记住"哪些预判错了"。

### 改动 1：地图原本说"只由官方考纲提供" —— 后来放开了

**当时的判断**：AI 画地图会漏考点、每次不一样、要等要网，所以要人工整理考纲。

**后来的实际**：这条对**主力板块**成立，但对"用户想学的其他章节"不成立——学生问"我在学虚拟语气，能不能用"，你说"没有这个考纲"，人就走了。

**现在的做法**：
- 内置章节 = 人工整理（高考数学·函数，42 个考点，有题库、有讲解、有卡片）
- 其他章节 = **AI 现场生成**，并做八道规整（保证图能画、不成环、不悬空）
- 两者在学习页里长得一模一样

**代价**：AI 生成的新章节只有骨架和题，没有预生成的讲解和卡片（那是下一步）。

### 改动 2：原本说"不让用户自己说学会了什么" —— 这条完全保留

**保留的理由在实现里被进一步证实了**：题库里那些"我很确定但答错"的记录，是最值钱的信号，说明错的概念已经扎根。这条设计没有动摇。

### 改动 3：原本说"AI 不乱动地图结构" —— 保留，但边界放宽

**现在的实际**：AI 可以生成一张新图（新章节），但**不能改已有图的结构**。同一张图每次打开都长得一样，用户永远找得到昨天那一格。

## 五、用户的一天（按现在的真实流程）

> 小林，高三，数学 90 分，想冲到 120。

1. **晚上 8 点，打开软件**。第一眼是**大厅**：
   - 最上面一个深色大按钮：开始学习新板块
   - 中间是我所有的板块：高考·数学 / 函数板块，已测 12/41，昨天
   - 下面是我的知识库：收藏了 18 张卡片
2. **点「继续学习」进学习页**。左栏是今天的三张卡：
   - 复习一下昨天学的（8 分钟）
   - 补一个最红的考点（13 分钟，3 道题）
   - 一共 21 分钟，在他设的"每天不超过 40 分钟"以内。
3. **点第二张卡**。进入做题，第一道做错了。屏幕问"这题错在哪？"，六个按钮，他点了"概念不清"。
4. **分数从 0.31 掉到 0.24，颜色从黄变红**。同时右栏多了一行：这个考点你 4 次错题里有 3 次是概念不清，建议先补它依赖的「复合函数定义」——并给了一个可以直接点过去的按钮。
5. **切到地图**。42 个格子里 3 个红、4 个黄、5 个绿、剩下灰的。他一眼看到红的那几块。
6. **点最红的那格**，右栏出现：讲解（AI 预先写好的 120 字）、两张卡片（点 ☆ 收进知识库）、"现出 3 道题"按钮。
7. **第二天打开**，第一张卡就是昨天那个红考点——因为软件判断"今天该再碰一次"。

> 注意这一天的重点：**用户从头到尾没有"制定计划"这个动作**。计划是长出来的，不是他写的。

## 七、十二个功能，每个说清三件事

> 读法：这个功能干什么 → 用户会看到什么 → 现状。

### 1. 考纲地图（F1）

**干什么**：软件得先知道"要学的东西有多少块"。
**会看到**：内置的高考数学·函数，42 个格子。想要别的章节，写个名字让 AI 现场拆。
**现状**：✅ 内置 1 份 + 任意章节可生成。生成时做八道规整（不能成环、不能悬空、必须有唯一根），保证图一定画得出来。

### 2. 初次校准（F2）

**干什么**：搞清楚"你现在什么水平"。
**会看到**：先勾"学到哪了"（1 分钟），再问要不要做小测（10 分钟）。小测每道题都挑"你大概七成能做对"的难度，答错会顺着前置考点往下钻。
**现状**：✅ 完整可用。**"答错就往下钻"是它最聪明的部分**——它不只判断你错在哪，还判断你是错在根上还是错在这一层。

### 3. 掌握分（F3）

**干什么**：给每个考点打一个 0 到 1 的分，再附一句"这个分有多可信"。
**会看到**：
- 分数越低越红；**没测过的是灰的，不是红的**
- 做过的题太少会标"数据不足"
- 详情里给区间，不给"N%"
**现状**：✅ 三件事一起算：学没学过 × 做得好不好 × 还记不记得。**记忆是打折，不是加分**。

### 4. 知识地图（F4）

**干什么**：把考点画成分层的图（不是一团星云）。
**会看到**：能点、能拖、能缩放；**默认不显示任何关系箭头**，点中哪个考点才显示和它相关的那几条，点空白处收起。
**现状**：✅ 两个视角：结构（我学到哪了）和缺口（哪块塌了）。
**删掉的功能**：原本有个"地基"模式会把整章前置关系全画出来，实测一团乱麻，已经删除。

### 5. 考点详情（F5）

**干什么**：点一个格子，右边出现的东西。
**会看到**：AI 讲解（120 字，说清是什么/怎么考/最容易错在哪）、两张可收藏的卡片、提问框、三档自评、地基链、前置与易混的理由、做题入口。
**现状**：✅ 全部可用。每块内容都能"用"——做题、收藏、跳转，不是只能读。

### 6. 做题与判分（F6）

**干什么**：选择题、填空题、判断题直接对答案。
**会看到**：交卷后三件事——对错 + 关键点、六个错因按钮、分数变化。
**现状**：✅ 判分对写法很宽容："3/2"和"1.5"算对，"根号2"和"√2"算对，全角半角都算对。

### 7. 错因分类（F7）

**干什么**：做错后点一个原因。
**为什么值得专门做**：因为不同原因要吃不同的药。而且它直接改变扣分：
| 错因 | 扣分狠不狠 |
|---|---|
| 算错了 | 几乎不扣——你其实会，只是手滑 |
| 看错题 | 几乎不扣 |
| 蒙的 | 中等 |
| 公式记错 | 扣 |
| 方法不会 | 扣得多 |
| 概念不清 | 扣最狠——下次还会错 |

**现状**：✅ 六种错因全部影响分数，还会给不同建议（比如"概念不清"会建议先补前置，并给一个跳转按钮）。

### 8. 今天的任务（F8）

**干什么**：每天给三张便利贴，不超过设定时长。
**会看到**：三张卡（到期复习 / 最红的缺口 / 要不要学新的），装不下就不给。
**现状**：✅ 按时长装箱（每张卡有固定耗时），超了就少给一张。

### 9. 问 AI 和收卡片（F9）

**干什么**：在某个考点里提问，AI 回答时顺带给出可收藏的小卡片。
**现状**：🟡 提问能用（需要开着一个小服务，见 3.3），卡片能收藏、能翻看、能删。**但收藏的卡片还没接进每日复习**——这是下一步最该做的。

### 10. 进度、倒计时和预估分（F10）

**干什么**：给"考高分"这个终极动机一个仪表盘。
**会看到**：距考试还有几天、测了多少个考点、预估分区间（比如 105±13）。
**现状**：✅ 一条数据都没有时显示"还没数据"，不假装算出一个分数。

### 11. 题目从哪来（F11）

**原计划**：手录 / 粘贴切题 / 导入文件。
**现在的做法**：**改成了按需生成**——
- 建章节时只备 7–9 道摸底题（约 20 秒）
- 用户点某个考点，才为它现做 3 道（约 6 秒）
- 每道题都做**独立复核**：出完再把题干丢回去重做一遍，答案不一致就丢掉重出（实测淘汰率约 1/4）

**为什么改**：用户看到图不等于要立刻做一百道题。预生成让建章节从 20 秒变 5 分钟，而且大部分题永远没人碰。
**现状**：✅ 内置板块有 147 道现成的；AI 生成的板块按需出题。

### 12. 数据存在哪、隐私怎么办（F12）

**干什么**：所有东西存在用户自己电脑上，不上传。
**现状**：✅ 不注册账号、不加好友、不做排行榜。问 AI 时只发"这个考点 + 题目 + 你的问题"，不发整个题库。钥匙只在小服务里，页面碰不到。

## 八、分数是怎么算出来的（不用公式，用比喻）

### 1. 每个考点的分数 = 三件事相乘

想象你要判断"小明会不会骑自行车"：

- **他学没学过**（有没有碰过车）——没学过，平衡感再好也是 0 分
- **他骑得怎样**（做对题的比率，越难的题做对越值钱）
- **他还记不记得**（上个月会，这个月不碰就生疏）

**分数 = 学过与否 × 骑得怎么样 ×（0.6 + 0.4 × 还记不记得）**

注意这里是**相乘**，不是相加。这一点很关键，我们踩过坑：早先写成"六成 + 四成"相加，结果五道题全错的考点还能显示橙色，第一道错题甚至会让分数上涨。改成相乘以后，全错就是红色。

> **所以你会看到**：从来没碰过的考点是**灰的**，不是红的。红的意思是"学过、做过、但塌了"。

### 2. "这个分数有多可信"也要算

只做了 1 道题就给分数，等于掷硬币。所以每个分数旁边有第二个数字：**可信度**。

- 做得少 → 可信度低 → 排今天的任务时**按保守值处理**（当作它可能更差）
- 做得少 → 不显示精确分数，显示"数据不足"

> **所以你会看到**：一个灰扑扑没测过的考点，也可能出现在今天的任务里，理由是"我们不确定，所以先去测一下"。

### 3. 记忆像一只漏水的水桶

- 答对一次，桶补满，漏水变慢（下次可以隔久一点再看）
- 答错一次，桶漏得更快（明天就得再看）

> **所以你会看到**：什么时候再复习，因人因题而异——不是统一的"7 天后"，而是"你在这个考点上大概第 5 天会忘"。

### 4. 挑哪道题做（像健身教练挑重量）

每次都挑一道"你大概有七成把握"的题。太简单没信息，太难只说明它超纲。

> **所以你会看到**：摸底开始几道刚刚好，答对几道后变难，答错会变简单。这是故意的。

### 5. 先补哪一个（"修路"的顺序）

假设城市里有十条路坏了，先修哪条？三个因素一起看：

1. **这条路多重要**（考频 × 分值）
2. **坏得多狠**（分数多低）
3. **它的地基有没有问题**（前置考点会不会）

第 3 条最容易被忽略，但它是这个软件区别于普通题库的地方：**地基没打好，先别盖二楼**。如果"复合函数"不行，那"复合函数求导"再红也先放一放。

另外两个加成：
- **"我很确定但答错"的考点优先**（错误概念扎了根，越晚越难改）
- **考前 30 天**：高分值考点加权，冷门的降权

### 6. 每天只给三张卡（像外卖装箱）

用户设了"我今天有 40 分钟"，软件按上面的顺序排好，一个个往箱子里装，装满就停。

## 九、风险与代价（按实际踩到的写）

| 风险 | 我们实际遇到的情况 | 现在的对策 |
|---|---|---|
| **没题可做** | AI 生成的新章节一开始一道题都没有 | 改成按需生成：建章节就备摸底题，点考点就现出 3 道 |
| **题目是错的** | 批量生成时真的出过：选项里没有正确答案、题干条件矛盾 | 每道题出完都做独立复核；题库还有一条"盲审"流程，已删掉 5 道错题 |
| **答案写法不同被误判** | "根号2"和"√2"被判错 | 判分前统一写法，还支持一道题多个可接受答案 |
| **章节串味** | 英语虚拟语气的章节里冒出导函数题 | 出题时必须带"考试 + 科目 + 章节"，题目严格属于当前章节 |
| **显示得太精确** | 一条数据都没有时显示"预估 103 分" | 没数据就显示"还没数据" |
| **AI 请求卡死** | 实测约 1/8 的请求会挂住不返回，一挂就是 5 分钟 | 所有 AI 请求加硬超时，挂了就重试或直接告诉用户 |
| **断网就废** | 浏览器直接调 AI 会被拦；双击版连本地服务都调不了 | 讲解卡片题目全部预生成；实时能力放到"本地小服务"里 |
| **桌面版打不开** | 在这台机器上 Electron 直接崩溃（环境问题） | 做"双击即开"的单文件版本当演示保底 |
| **地图一团乱麻** | 前置箭头全画出来自己也看不懂 | 删掉"地基"模式，改成点谁看谁 |
| **点进去关不掉** | 添加板块的向导没有关闭按钮，只能刷新页面 | 所有浮层都能 ✕ / Esc / 点空白关掉 |
| **功能越做越多** | 按钮挤成三行 | 砍到九个，挪进设置 |

**一句话总结风险**：这个产品最容易失败的地方**不是算法**，而是**题从哪来**和**第二天会不会再打开**。

## 十、比赛现场能演什么（3 分钟）

评委看四样：**需求真不真（25%）/ 现场跑不跑得通（30%）/ 有没有真人用过（25%）/ 值不值得做下去（20%）**。其中"跑得通"权重最高。

**建议脚本（按现在真实的界面）：**

| 时间 | 屏幕上做什么 | 你嘴上说什么 |
|---|---|---|
| 0:00–0:20 | 打开软件，**大厅**：我的板块、进度、上次学习时间 | "备考的人不缺资料，缺的是'今天到底该干哪三件'。" |
| 0:20–0:45 | 点「添加板块」→ 写"虚拟语气" → **20 秒后一张 20 个考点的图出现** | "考纲里没有的章节，也能现场拆出来。" |
| 0:45–1:20 | 点一张任务卡 → 故意答错 → 点"概念不清" → **右栏分数掉、颜色变红** | "它知道你错在哪一类，也知道该先补地基。" |
| 1:20–1:50 | 切到图谱 → 点一个考点（**箭头才出现**）→ 点空白收起 | "图默认是干净的，点谁才看谁的关系。" |
| 1:50–2:20 | 切热力表 → 指着"难"那列 | "能看出是简单题不会，还是难题崩——这两种补法完全不同。" |
| 2:20–2:45 | 点「现出 3 道题」→ **6 秒后题目出现** | "题库不预生成，用到才做，所以建章节只要 20 秒。" |
| 2:45–3:00 | **关掉小服务 / 拔网线**，回大厅点别的板块 → 一切照常 | "断网也能用。AI 只是加速器，不是发动机。" |

**演示的四个坑**（务必避开）：

1. 现场等 AI 慢慢吐字 → 讲解和卡片都是预生成的，现场只演"秒出"
2. 现场让评委看你建 100 道题的题库 → 只演"现出 3 道"
3. 展示两千个格子的炫技大图 → 只演一个章节 42 个格子
4. 花 40 秒讲算法 → 一句话带过，把时间留给"颜色变了"

## 十一、还没做的和为什么不做

### 下一步要做的（按性价比排序）

| 顺序 | 要做什么 | 为什么 | 大概工时 |
|---|---|---|---|
| 1 | **卡片接进每日复习** | 现在收藏了不会自动复习，等于收藏动作没回报 | 2 小时 |
| 2 | 设置里加"清空当前板块题库" | 早期生成的脏数据清不掉 | 20 分钟 |
| 3 | 出题边出边存 | 出题过程中刷新会丢那批题 | 30 分钟 |
| 4 | 新章节也生成讲解和卡片 | 现在只有内置章节有 82 张卡 | 40 分钟 |
| 5 | 题库继续扩容 | 现在每考点 3–7 道，热力表每格样本偏少 | 按需 |

### 明确不做（写进"未来"页，不假装做了）

拍照识别题目、主观题自动判分、手机版、云同步、多人协作、语音功能、账号体系。

## 十二、名词对照表

| 文档里的说法 | 人话 |
|---|---|
| 掌握度 / M | 掌握分，0 到 1，越接近 1 越稳 |
| 可信度 / conf | 这个分数有多可信（做得少就不可信） |
| 覆盖率 / K | 学过没有（有没有碰过这辆车） |
| 能力 / A | 做对的比例，难题做对算得更重 |
| 保持 / R | 现在还记不记得 |
| 间隔重复 | 按"你会忘的速度"安排复习，不是统一七天 |
| 自适应选题 | 每次都挑一道你大概七成能做对的题 |
| 缺口优先级 / P | 先补哪个的顺序：重要性 × 坏的程度 × 地基 |
| 前置闸门 | 地基没打好，先别盖二楼 |
| 疑似蒙对 | 三秒答对，算你蒙的，这次不算数，五天后重测 |
| "我很确定但答错" | 最值钱的红旗：错的概念已经扎根了 |
| 卡片 / 闪卡 | 一张能反复看的小纸片 |
| 热力表 | 横竖都有的表格版体检报告 |
| **考纲包 / 板块** | 一个章节的完整数据（考点 + 题 + 你的记录） |
| **按需生成** | 不提前做一百道题，你点哪个考点才为它现做三道 |
| **独立复核** | 题出完再让别人（另一个 AI）重做一遍，答案对不上就丢掉 |
| **八道规整** | AI 生成的图可能成环、悬空、没根，软件自动修理 |

| **抢分模式** | 考前一个月，只推高频高分考点，冷门的先藏起来 |
